# Анализ: Supabase не используется в проекте

## Результат проверки
Пользователь спросил, все ли команды обращаются только к локальным файлам, без обращения к серверу.

**Ответ: Да, подтверждено.** Весь контент загружается из локального JSON-файла `products.data.json`.

## Что найдено как мёртвый код
- `@supabase/ssr`, `@supabase/supabase-js` в package.json — нигде не импортируются
- `src/lib/db.ts` — подключение к PostgreSQL, нигде не используется
- `src/lib/sqlite-cache.ts` — SQLite кеш, нигде не используется
- `api/db/schema.ts` + `drizzle.config.ts` — схема для миграций, но БД не используется
- `.env` / `.env.local` — содержат `DATABASE_URL`指向 Supabase, но не используются

## Нет задачи на реализацию
Пользователь только подтвердил факт. Нет плана изменений.
